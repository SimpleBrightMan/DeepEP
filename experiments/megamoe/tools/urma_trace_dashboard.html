指标口径与使用说明
  • allrank 默认突出各 rank 指标的算术均值，逐 rank 明细收在下方，可按需展开；点击数字查看完整计算过程。
  • 总耗时统一采用 JSON 中该 rank 的诊断跨度，包含记录范围内的空泡；不是关闭 timer 后的性能结果。不同 rank 使用各自的时间轴。
  • 通信带宽按组内其它卡与跨组分别统计，为单向聚合有效带宽；本卡已融入 Pack / GMM2 的路径不计入。默认使用 trace 中的实际字节；可切换为元素字节数模型重算。
  • 理论通信时间固定包含 Dispatch + Combine，两阶段分别按元素字节数估计跨组流量后相加。它是理论下限，包含假设的路由均衡和链路效率。
  • GMM 计算量按 GEMM 的乘加计 2 FLOPs；非矩阵操作不计入 MFU。理论单卡峰值必须与数据类型、精度及稀疏性口径一致。
  • “≈” 表示结果包含估算；无法可靠计算的项显示“—”，点击仍可查看原因。原始 JSON 不会被修改或上传。
