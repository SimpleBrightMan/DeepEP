# 文档图稿

`architecture.svg` 为中文架构图，由[中文首页](../README.md)及[架构文档](../docs/architecture.md)引用；`architecture_en.svg` 为对应的英文架构图，由[英文首页](../readme_en.md)引用。两图展示相同的接口、业务与执行、设备实现及平台依赖。

实线箭头表示调用或启动，虚线箭头表示支撑或依赖；虚线框标识实验性 MegaMoE API 和可选计算与通算融合模板。图中层次描述目标架构，实现与验证进展见[路线图](../docs/roadmap.md)。

图稿为自包含 SVG，不引用外部图片或脚本。调整架构时同步核对 [架构说明](../docs/architecture.md) 与 [目录设计](../docs/repository-layout.md)。
